Each cell shows the policy: four arrows, each as long as the probability of taking it. At the start every arrow is the same length — the agent has no opinion about anything. It practises from a random square each episode; the line drawn is a separate run from the black dot in the corner, green if it reached the goal, red if it fell in.

Nothing here is told the right move. It plays, it gets one number at the end, and every action in that episode is nudged by how the episode went.
