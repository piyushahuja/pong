Neurons as Matrix Rows

Every neuron is one row of the weight matrix

A blue circle is a neuron. It has its own weight to every coordinate of the input, so the layer holds input_dim × hidden_dim weights in total. Those weights are not scattered — they stack into a single matrix, one row per neuron, one column per input coordinate. Hover anything below; the other panel answers.

Why rows and not columns. The layer computes h = W x. Matrix–vector multiplication takes the dot product of each row of W with x, and produces one number per row. One row in, one neuron's activation out — so row count must be hidden_dim and column count must be input_dim.

The argument order is a trap. You write nn.Linear(input_dim, hidden_dim), but the tensor it stores is .weight of shape (hidden_dim, input_dim) — transposed relative to how you typed it. In pong.py that is nn.Linear(6400, 200) holding a (200, 6400) matrix: 1,280,000 weights, every one of them a line in a picture far too dense to draw.
