# Lectures

Notes, derivations and visualisations that go alongside the notebooks — the longer-form
material that does not belong in a worksheet.

Worksheets teach the mechanism you need to run the code. This is for the surrounding ideas:
why a technique works, where it came from, what it connects to elsewhere.

| File | About |
|---|---|
| `information.md` | Representation design: transforming raw observations so the task-relevant structure is easier to see. Frame differencing, frame stacking, invariance, sufficient statistics, and why Pong's preprocessing is an instance of something general. |

Anything goes here: markdown notes, images, diagrams, standalone HTML visualisations. Keep
generated artefacts out — if a figure is produced by code, the code belongs in the repo and
the output belongs in `outputs/`, which is gitignored.
