# Borrowed figures

These five figures come from Andrej Karpathy's "Deep Reinforcement Learning: Pong from Pixels"
<https://karpathy.github.io/2016/05/31/rl/>, and are used in slides of lecture 2:

| File | Slide it carries |
|---|---|
| `pong.gif` | Pong from pixels, the game itself |
| `episodes.png` | Four games, two won and two lost, for credit assignment |
| `policy.png` | The two-layer policy network |
| `sl.png` | Supervised learning: the label is known, the multiplier is 1 |
| `rl.png` | Policy gradients: no label, so the return supplies the sign |

They are his, not ours. The four other figures from that post are not kept here because no
slide uses them.
